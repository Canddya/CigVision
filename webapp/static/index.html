使用说明
卷烟盒外观质量检测使用说明
操作步骤
  1. 选择或拖入 1–100 张 JPG、PNG 或 BMP 图片。
  2. 点击“上传并开始检测”。模型未就绪时，可先上传并查看图片。
  3. 检测过程中，进度和每张图片的类别、置信度会自动更新。
  4. 点击“查看”预览原图；点击“导出 CSV”保存当前批次结果。
接入训练模型
将可信的 CigYOLO 分类权重复制到项目的 params/best.pt，点击工作台的“重新加载”。也可以在启动前通过 CIGYOLO_MODEL 指定路径。
模型必须是包含 Right（良好）和 Wrong（缺陷）的 YOLO 分类模型。没有模型时不会生成预测结论。
结果说明
置信度表示模型对当前分类的概率估计，不代表检测准确率。本软件判断整张图片的包装外观类别，不输出缺陷位置。推理耗时包含图片读取与模型预测，首张图片可能较慢。
记录与运行
图片和 SQLite 数据保存在本地项目的 db/ 文件夹。服务重启后可以从检测记录重新打开批次；中断或失败的批次可重新检测。每次仅运行一个批次。
